# MSPDI fixtures

- `handwritten-msp2016-style.xml`: written by hand to look like a Microsoft Project 2016 XML
  export, with features Super PM does not support yet, to test the import report. It is not
  real Microsoft Project output.

Real reference files from the owner (spec section 8) go here as they arrive. Each should come
with the dates Microsoft Project calculated, for golden tests of the scheduling engine.
